# ORBIT 1.0 — 配布版について

2026-10-18。ブラウザー版をビルド済み。実機用ビルドは同梱の GitHub Actions で行います。実機書き込み・起動・純正復帰は未検証です。公開手順は `web/orbit-site/guide.html` を参照してください。以下には開発時の仕様・検証記録も含みます。

# ORBIT Browser Lab 0.2

FM-1の液晶・ノブ・ボタン・鍵盤を操作できるアンビエント制作環境です。Cで実装した音源・ユークリッドシーケンサー・画面描画をWebAssemblyで実行します。

## 起動

ZIPを展開し、macOSでは「起動.command」をダブルクリックしてください（Python 3が必要）。表示されたローカルURLを開き、「電源を入れる」→「再生」で試奏できます。ターミナルからは `python3 serve.py` でも起動できます。終了はControl+C。HTMLの直接起動（file://）には対応していません。

## 4つの独立したユークリッドシーケンサー

各トラックのBPM・GRID・HITS・ROT・DIVは独立しています。HITS個の発音をGRID個の区切りへ均等に配置します。個々のステップを手入力する方式ではありません。

| 項目 | 操作 |
|---|---|
| BPM | トラックのテンポ、10〜120 |
| GRID | 1周の区切り数、1〜64 |
| HITS | 1周の発音数、0〜GRID |
| ROT | 発音位置を回転、0〜GRID−1 |
| DIV | 各区切りの音価。1/4は1拍につき1区切り |
| MODE | FLOW：音程が徐々に変化。HOLD：生成済みの音程を保持。PAUSE：新しい発音を休止 |

円周上の点が発音位置、移動する表示が現在位置です。数値欄で直接編集でき、トラックボタンを押すと実機液晶にもそのトラックのEUCLIDページが開きます。実機パネルではSEQでEUCLID / PULSEページを選択し、4つのノブで編集します。ノブは上下ドラッグ・ホイール・矢印キーに対応します。

HOLDであってもグリッドや発音位置を変えると新しい位置の音程が生成されます。PAUSEや停止後も長いリリースと残響は続きます。共通BPMを変えても各トラックのテンポは変わりません。初期状態は内部クロックです。外部MIDIクロックはトランスポート等に影響しますが、各トラックのテンポを同期させる用途には対応しません。

| トラック | 音色 | BPM | GRID | HITS |
|---|---|---:|---:|---:|
| 1 | MIST | 43 | 13 | 4 |
| 2 | VEIL | 57 | 17 | 5 |
| 3 | TIDAL | 31 | 11 | 3 |
| 4 | DUSK | 67 | 19 | 7 |

## 音色・エフェクト・再生成

4つのプリセットは、遅い立ち上がりと長い余韻、低いフィルター、デチューン、ノイズを組み合わせた曖昧な音色です。リバーブの残響時間と送り量、ディレイの帰還と送り量、コーラスの深さ、歪みの強さを拡張しました。リバーブ量を上げるほど原音が奥へ下がります。出力リミッターは維持しています。

「↻ 全体を再生成」で4トラックのテンポ・グリッド・発音数・回転・分割・移調・音色・エンベロープ・定位・変調・エフェクトと、共通のルート／スケールを新しい組み合わせにします。音源方式・プリセットも抽選し、音色は音源ごとの有効範囲全体から選びます。マスター音量やMIDI接続設定は変更しません。再生中なら再生を続けます。

ENV、FX、SCLなどの実機ボタンでも詳細を編集できます。消音はブラウザー出力だけを止めます。MIDI入力は対応ブラウザーで利用できますが、実際の外部機器接続は未検証です。

## 保存

停止後、音源が静まりオートセーブが行われるまで待ってから閉じてください。長いリリースと保存待ち時間があるため、停止直後には保存されません。SAVE操作も利用できます。仮想フラッシュを同じブラウザー・同じURLのlocalStorageに保存します。

保存キーは `orbit-02-browser-flash`。0.1とは独立し、自動変換しません。「初期状態に戻す」は確認後に0.2の保存状態を消去します。サイトデータ削除やプライベートモードでは保存を維持できない場合があります。実機との直接転送やクラウド同期はありません。

## 検証

- 全GRID 1〜64について発音数・回転・間隔の均等性を検証。
- 30／60／90／120 BPMの独立進行と、共通BPMからの独立を検証。
- HOLD、再生成、同一シードの再現性、保存／復元を検証。
- 100シーンのパラメーター範囲、48秒の4トラック音声、AddressSanitizer、CPU2無効構成を検証。
- WASMで16種類の再生成シーンを6秒ずつ再生し、音声が有限であることを検証。
- ネイティブCとWASMで132,352ステレオフレームの音声が完全一致。
- Codex内蔵ブラウザーで実機GUI、数値入力、再生成、再生／停止を確認。

ログは `validation.txt`。実機の書き込み・起動・CPU負荷・USBは未検証です。WASMはブラウザー用で、FM-1へ書き込めるファイルではありません。

## ソースと再ビルド

`ORBIT-browser-source.zip` に変更済みファームウェア、音源ソース、Webコード、テスト、ライセンスを同梱しています。Emscripten 6.0.12、Python 3（Pillow、fontTools）、Node.js、clangを使用しました。Emscriptenの環境を有効化して `sh web/emu/build_orbit.sh` を実行してください。Cの試験は `sh tests/run_orbit.sh`。Pillowにlibraqmがない環境はBASIC描画を使うため、フォントのカーニングが異なる場合があります。

## 再生中の音色変更（0.2修正）

MODEの初期値をFLOWに統一しました。PRESETSによる音色変更や音源切り替えで、MODE・BPM・GRID・HITS・ROT・DIV・GATE・移調を保持します。HOLDやPAUSEを明示的に選んだ場合もその選択を維持します。音源切り替え時には現在の発音を解放するため、波形の完全な連続切り替えではありませんが、シーケンサーは次の発音を継続します。既存プロジェクトで保存されたPAUSEは自動変更しません。

## 円形波形と4音源の重ね表示

HOMEの波形を、時間を角度・振幅を半径に対応させた円形表示に変更しました。無音時は基準の円になります。HOMEの表示設定がTRACKS/LEVELSの場合は従来のトラック表示です。

HOMEボタンの巡回は HOME → MIXER → OSC x4 → CLOCK → HOME。OSC x4では4トラックの音源出力（エフェクト前）を緑・オレンジ・青・ピンクで重ねます。各トラック内の発振器を分離する表示ではありません。振幅は見やすさのため自動拡大し、音量の厳密な比較用ではありません。ブラウザーの「◎ 4音源の波形」からも直接開けます。音声を再生したまま切り替えできます。

表示用バッファは約2 KBを追加します。ブラウザーの描画・4トラック個別波形・無音時の更新・音声一致を検証済みです。実機のメモリーと描画負荷は未検証です。

## OSC x4：全体フィルター

ノブ1 FILTER（0〜127）は全体のローパスフィルター。0はバイパス、右へ回すほど高音が減って暗く柔らかくなります。ノブ2 RESはレゾナンス。4トラックとディレイ／リバーブなどの戻りを含むステレオ出力全体へ適用します。ノブ3・4は未割り当てです。パラメーター変更は滑らかに補間し、出力リミッターを維持します。

プリセット変更や全体再生成でもフィルター設定を保持し、プロジェクト／オートセーブにも保存します。円形の4本の波形は従来どおりフィルター前の各音源を示します。既存ORBIT 0.2の未使用グローバル領域を使うため保存サイズは変更していません。元のFeluccaの古い形式との設定互換性は保証しません。

## 音源方式も含めたランダム再生成

「全体を再生成」は各トラックで使用可能な13種類の音源方式から独立に抽選します。ANALOG、FM6、PHASE、LOFI、SAMPLE、VOICE、TRIO、WHEEL、GRAIN、PHYS、NOISE、SLICE、DRUMが対象です。同じ方式が複数トラックに選ばれることもあります。廃止されたDIGITAL予約枠と空のFM6ユーザーバンクは対象外です。

プリセットを抽選した上で、音源固有の8項目をそれぞれの有効範囲全体からランダム化します。ADSR、フィルター種類、エンベロープ変調、LFO速度と波形、各エフェクト送り量も広い範囲で変化します。初期起動シーンの4つのアンビエント音色は維持し、再生成時には固定しません。画面のP番号は選択した元プリセットで、最終音色はランダム編集済みです。

再生状態、FLOWの初期値、マスター音量、全体フィルター、出力リミッターは維持します。リズムはユークリッド方式です。ランダムな音色によって短い音・ノイズ・打楽器・非常に小さい音が生じることがあります。


## 1.0 ENV修正（2026-10-18）
FM6、DRUM、LOFI STEPのADSR上書きとSLICE ONEのリリース解除を修正しました。全13音源でENVが音量に作用します。音源固有の減衰やサンプルが先に終了した場合、RELを長くしても終了した素材を引き延ばすことはありません。旧ブラウザータブは再読み込みし、電源を入れ直してください。保存済みプロジェクトの値は維持されます。


## 実機パネルで全体再生成
HOMEでOSC x4を開き、OCT−とOCT＋を同時に1秒以上長押しします。HOLD 1s: REGEN → REGENERATEDと表示します。押し続けても1回のみで、両方を離して再操作できます。このページではOCT±はオクターブを変更しません。再生／停止状態と全体フィルター、マスター音量を保持します。事前にPROJECTへ保存してください。実機そのものの動作は未検証です。

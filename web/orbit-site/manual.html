01 / まず音を出す

ORBITは、4トラックそれぞれに異なる周期を与え、音色と残響を重ねるアンビエント制作環境です。ステップを一つずつ打ち込む代わりに、ユークリッドシーケンサーで発音位置を作ります。

  1. ブラウザー試奏を開き、「電源を入れる」を押します。
  2. 「▶ 再生」またはパネルのPLAYを押します。初期シーンはゆっくり立ち上がるため、数秒待ってください。
  3. トラック01〜04から一つ選び、BPMやHITSを変えます。
  4. ENVで音の立ち上がり、FXで残響を調整します。
  5. 気に入ったら停止し、PROJECTに保存します。

このマニュアルはORBIT 1.0のENV修正版に対応します。実機風GUIと実機用ソースの操作を説明していますが、実機への書き込み・起動・純正復帰は未検証です。ブラウザー版はUSB接続なしで試せます。

02 / パネルの基本操作

操作子役割

PRESETS音色プリセットを切り替えます。
KNOB 1〜4液晶下部の左から4項目に対応します。ページによって役割が変わります。
PLAY / STOP全体の再生・停止。停止後もリリースと残響が残ることがあります。
SEQEUCLIDとPULSEを切り替えます。
ENV / LFO / FX / SCL / EDIT対応する編集ページを開きます。同じボタンを押すと同じ系統の次のページへ進みます。
HOMEHOME → MIXER → OSC x4 → CLOCKを巡回します。
SAVEUSER → PRESETS → PHRASES → PROJECT → TOOLSを巡回します。音色保存とプロジェクト保存は別です。
OCT− / OCT＋通常は鍵盤のオクターブ変更。保存画面などではキャンセル・実行・確定に使います。画面下の案内を確認してください。

ブラウザーでの操作

ノブは上下ドラッグ、ホイール、フォーカスを当てた状態の矢印キーで操作できます。Shiftを押しながらボタンをクリックすると押したままの状態になり、再操作で解除します。画面上の数値入力とトラックボタンはブラウザー専用の補助操作です。

トラックボタンを押すと、そのトラックのEUCLID画面が開きます。「消音」はブラウザー出力を止める操作で、シーケンサーの停止とは異なります。

03 / ユークリッドシーケンサー

GRID個の区切りの中に、HITS個の発音をなるべく均等に配置します。たとえばGRID=8、HITS=3なら、8区切りを一周する間に3回発音します。ROTで配置を回転させます。4トラックのテンポと周期は独立しています。

実機パネルでの設定

  1. ALGORITHMでトラックを選びます。
  2. SEQを押してEUCLIDを表示します。
  3. KNOB 1〜4でBPM・LEN・HITS・ROTを編集します。LENはブラウザー欄のGRIDと同じ意味です。
  4. SEQをもう一度押してPULSEへ移動し、DIV・GATE・MODE・TRNを設定します。
  5. PLAYを押します。再生中も変更できます。
ページノブ項目働き
EUCLID1BPM10〜120。選択トラックのテンポ。
EUCLID2LEN / GRID1〜64。一周の区切り数。
EUCLID3HITS発音数。0は無発音。GRIDより大きくても実際の発音数はGRIDまでです。
EUCLID4ROT発音位置を回転。内部値0〜63をGRIDで折り返して使用します。
PULSE1DIV各区切りの音価。1/4は1拍に1区切り、1/8は1拍に2区切り。
PULSE2GATE各発音でノートを保持する長さ。ノートオフ後はENVのRELに従います。
PULSE3MODEFLOW / HOLD / PAUSE。下記参照。
PULSE4TRN選択トラックの移調。

FLOW・HOLD・PAUSE

  • FLOW：初期モード。発音位置の音程を徐々に再生成します。毎回必ず違う音になるわけではありません。
  • HOLD：すでに生成された音程を保持します。GRIDやHITSを変えて未生成の位置が有効になると、その位置の音程は新たに生成されます。
  • PAUSE：そのトラックの新しい発音を休止します。鳴っている余韻は直ちには消えません。

DIVは1/4、1/8、1/16、1/32、8T、16T、1/2、1/1、2BAR、4BARを選べます。Tは三連の分割です。長いDIVと長いGATEを組み合わせると、ゆっくり立ち上がる音を作りやすくなります。

CLOCKの共通BPMやSELECTを変えても、ORBITの各トラックのBPMは変わりません。外部MIDIクロックで4トラックを共通テンポへ同期させる用途には対応していません。

重なりを作る例

トラック1をBPM=40、GRID=13、HITS=3、トラック2をBPM=53、GRID=17、HITS=4にします。両方をFLOW、DIV=1/4から始め、片方のROTを少し変えてください。音の重なる位置が時間とともに移動します。

04 / 音源と音色を選ぶ

まずトラックを選び、PRESETSを回して音色を探します。SAVEからPRESETSページを開くと音色リストを使えます。EDIT 1 / EDIT 2には、その音源固有の8項目が4項目ずつ表示されます。ノブ名は方式・モードによって変わるため、液晶に表示されたラベルを基準に操作してください。

音源音作りの方向
ANALOG波形・フィルターを使う基本的なシンセ。柔らかいパッドの出発点。
FM66オペレーターFM。倍音の多いベル、金属音、変化するパッド。
PHASE位相を扱う音源。輪郭や倍音の変化を探します。
LOFIチップ音・粗いデジタル質感。STEPモードも共通ADSRが効きます。
SAMPLEサンプル素材を使った音色。素材自体の長さが発音に影響します。
VOICE声を思わせるフォルマント音色。
TRIO複数の音を重ねた厚みのある音色。
WHEELオルガン系の持続する倍音。
GRAIN粒状に分解したテクスチャー。
PHYS物理モデルによる弦や共鳴の質感。
NOISEノイズを中心にした風・ざわめき・背景音。
SLICE素材を区切って鳴らす音源。
DRUM打楽器キット。短い打音を残響で広げる用途にも使えます。

再生中のプリセット切り替えでも、BPM・GRID・HITS・ROT・DIV・GATE・MODE・移調を保持し、次の発音を続けます。音源切り替えでは現在の発音を解放するため、音が完全につながったまま切り替わることを保証するものではありません。

音色編集の進め方

  1. 一つのトラックだけを聴ける状態にします。
  2. FXのDLYとREVを一度減らして原音を確認します。
  3. EDITで音の素材・倍音を決めます。
  4. ENVで発音の輪郭を作り、LFOでゆっくり揺らします。
  5. 最後にFXを戻して空間に広げます。

05 / 発音エンベロープ（ENV）

ノブ表示働き
1ATK発音開始から最大音量へ向かう時間。上げるとゆっくり立ち上がります。
2DEC最大音量からSUSの音量へ向かう時間。
3SUSノートが保持されている間に向かう音量。時間の設定ではありません。
4RELノートオフから消えるまでの余韻。

全13音源で共通ADSRが音量に作用します。FM6のオペレーターエンベロープや打楽器固有の減衰は、その内側で引き続き作用します。FM6のOP ENVは各オペレーターの音色変化、通常のENVはトラックの発音の輪郭を調整するものです。

GATEが短すぎると、長いATKの途中でノートオフになります。音が小さい場合はまずGATEやDIVを長くしてください。また、サンプルや打楽器が先に鳴り終わった場合、RELを上げても終了した音を引き延ばすことはできません。リバーブの余韻はRELとは別に残ります。

ENV DEST

ENVをもう一度押すと、エンベロープからフィルター・ピッチ・音色への変調量を設定できます。ノブ1がFLT、2がPIT、3がSHP、4がESYNCです。変調の具体的な音への作用は音源によって異なります。ESYNCをオンにするとATK・DEC・RELが共通テンポに対応する音価になります。トラック独立BPMに自動追従する設定ではありません。

試し方

FXを少なくし、持続するANALOG音色で鍵盤を押し続けます。SUSを高め、ATKを短い値と長い値で比較してください。次にSUSを下げてDECを変え、最後に鍵盤を離してRELを比較します。数値入力の0〜127は音源内部の値で、秒数そのものではありません。

06 / LFO・スケール・定位

LFOでゆっくり動かす

LFOページでは、ノブ1から速度・波形・開始位相・フェードインを調整します。LFO 2では同期・再トリガー・極性を設定し、LFO DESTではピッチ、フィルター、音色、音量への変調量を設定します。最初は低速・少量から始めると、長い音を自然に揺らせます。

MODページは追加の変調割り当てです。ノブ1でスロット、2で変調元、3で変調先、4で量を選びます。意図しない動きがあるときは、LFO DESTとMODの両方を確認してください。

SCL

SCLの4つのノブはROOT・SCALE・QUANT・TRANSです。ルートとスケールで音程のまとまりを作り、TRANSで音域を変えます。HOLDで保持中の生成済み音程が、設定変更だけで直ちに全て作り直されるわけではありません。

MIXERとVOICE

HOMEからMIXERへ進み、選択トラックのLEVEL・PAN・REV・MUTEを調整します。ALGORITHMで対象を切り替えます。EDIT内のVOICEページでは発音方式やGLIDE、VOICE 2では割り当て・DETUNE・PAN・MUTE、VOICE 3ではSPREADを編集できます。MONOやUNISONにすると重なり方が変わるため、まずPOLYで音作りを始めると把握しやすくなります。

07 / エフェクトと全体フィルター

FXページの送り量は選択トラックごと、DLY・REVERB・CHORUSページの設定は共通です。トラックの送り量が小さいと、共通の残響設定だけを変えても効果を感じにくくなります。

ORBITでは残響・帰還・変調・歪みを強く設定できるようにしています。音が埋もれる場合は、まず各トラックのDLYとREVを下げて原音を確かめてください。リミッターがあっても聴感上の大きさは変わるため、出力音量を控えめにして調整します。

SLICER / INSERT

SLICERは音量を周期的に区切る効果です。ノブ1からオン／モード、パターン、速度、深さを調整します。INSERTでは効果の種類とA・B・C、INSERT 2では原音と効果音のMIXを設定します。A・B・Cの意味は選んだ効果で変わります。

OSC x4のFILTER

HOMEを押してOSC x4を開きます。FILTER=0はバイパス、値を上げるほど高音が削られて暗く柔らかくなります。RESはフィルターの共鳴感です。4トラックとディレイ／リバーブの戻りを含む出力全体にかかります。プリセット変更・再生成でも設定を保持し、プロジェクトにも保存します。

08 / 円形波形の読み方

HOMEの波形表示は、時間を円周方向、振幅を半径方向に対応させています。無音時は基準の円になります。HOMEがTRACKS / LEVELS表示になっている場合は波形以外の表示になります。

HOME → MIXER → OSC x4と進むか、ブラウザーの「◎ 4音源の波形」を押すと4本の波形を重ねて表示できます。緑・オレンジ・青・ピンクが4トラックに対応します。

表示しているのは各トラックのエフェクト前の音源出力です。一つの音源内部の4個の発振器を分離しているわけではありません。また表示は自動拡大されるため、円の大きさだけで音量を正確に比較できません。全体フィルターを動かしても、この表示はフィルター前のままです。

09 / 全体を再生成する

実機パネルのショートカット

  1. HOMEを押し、OSC x4ページを表示します。
  2. OCT−とOCT＋を同時に押し続けます。液晶に「HOLD 1s: REGEN」と表示されます。
  3. 両方を1秒以上押すと全体を再生成し、「REGENERATED」と表示します。
  4. 両方のボタンを離します。次の再生成も同じ操作です。

1秒未満で離せば再生成しません。押し続けても1回だけ実行します。再生中は再生を継続し、停止中は停止したままです。マスター音量・全体フィルターは保持します。OSC x4ではOCT−／OCT＋をこの操作に使うため、単独押しでもオクターブは変更しません。他のページやメニュー・保存確認・名前入力中は、このショートカットでは再生成しません。気に入った状態は実行前にPROJECTへ保存してください。

ブラウザーで実機パネル操作を試す場合は、OSC x4を開き、Shift＋クリックでOCT−とOCT＋を順に押したままにします。1秒後に再生成されたら、両ボタンを再度Shift＋クリックして解除します。

ブラウザーの「↻ 全体を再生成」を押すと、4トラックを新しい組み合わせにします。実機パネルでは、HOMEを押してOSC x4ページを開き、OCT−とOCT＋を同時に1秒以上長押しすると、同じ全体再生成を実行できます。

変わるもの保持されるもの
音源方式・元プリセット・音源固有の8項目・ADSR・変調・エフェクト送りマスター音量・全体フィルター・MIDI接続設定
トラックのBPM・GRID・HITS・ROT・DIV・移調・定位・ルート／スケールなど再生中なら再生状態を継続

各トラックで13音源から独立に選ぶため、同じ音源が複数トラックに選ばれることもあります。表示のP番号は元プリセットの番号で、最終音色はランダム編集済みです。短い音、ノイズ、打楽器、非常に小さい音も生成されます。必ず柔らかなパッドになる機能ではありません。

音源固有の値は各項目の有効範囲から選びます。テンポやリズムは実装された範囲内で生成されます。お気に入りの状態は再生成の前にPROJECTへ保存してください。画面に前の生成結果へ戻す専用ボタンはありません。

10 / プロジェクトと音色の保存

4トラック全体をPROJECTへ保存する

  1. PLAY / STOPで停止します。
  2. SAVEを繰り返し押し、液晶にPROJECTと表示されるページを開きます。USERは音色用なので、全体保存にはPROJECTを使います。
  3. KNOB 1で保存先を選びます。4スロット（A〜D／内部値1〜4）です。
  4. KNOB 4を右へ回してSAVEを選び、画面下の実行案内を確認してOCT＋を押します。
  5. 使用済みスロットなら上書き確認が出ます。内容を確認し、OCT＋で進みます。OCT−はキャンセルです。
  6. 名前入力画面で、KNOB 1でカーソル、KNOB 2で文字を編集します。PROJECTではKNOB 3でランダムな名前も選べます。
  7. OCT＋で保存を確定します。保存完了を確認してからページや電源を閉じます。「STOP TO SAVE」と表示されたら再生状態を確認してください。

読み込む・削除する

PROJECTでKNOB 1から対象を選び、KNOB 3を右へ回してLOADを選択し、OCT＋で読み込みます。現在の編集を残したい場合は先に保存してください。KNOB 2はERASEです。削除の確認画面では対象を確かめてから実行してください。

音色だけを保存する

SAVEのUSERページでスロットを選び、SAVEを実行して名前を確定します。これは音色の保存であり、4トラックのシーケンサーと共通設定をまとめたPROJECT保存とは用途が異なります。

ブラウザーのオートセーブ

停止して音源が静まり、保存待ち時間が過ぎると現在の状態を自動保存します。停止直後に閉じると最後の変更が残らないことがあります。大切な状態はPROJECTへの明示保存も行ってください。

ブラウザー保存は同じブラウザー・同じオリジン（プロトコル、ホスト、ポート）内です。127.0.0.1:8765と127.0.0.1:8766、ローカル版と公開サイトは別の保存領域になります。サイトデータ削除・プライベートモード・「初期状態に戻す」による消去に注意してください。クラウド同期や実機への自動転送はありません。

「初期状態に戻す」は確認後、このブラウザー版の保存状態を消して初期シーンを読み込みます。プロジェクト保存はサイトデータ消去に対する外部バックアップにはなりません。実機の全体バックアップ・純正復帰は公開・更新ガイドを参照してください。

11 / アンビエント制作の例

霞のようなパッド

ANALOGを選び、長めのATKとREL、持続するSUSにします。DIVを1/2または1/1へ伸ばしてATKの時間を確保し、HITSを少なめに設定。フィルターを暗くし、弱いLFOとHALLの残響を足します。

遠くで鳴る金属音

FM6のベル系音色を出発点に、ATKを短め、SUSを低めにします。各トラックのBPMとGRIDを少しずつ変え、ディレイの送りとリバーブを増やします。共通ADSRに加えて、OP ENVの設定も音の長さに影響します。

波のように動く背景

NOISEまたはGRAINを選び、低速LFOを音量やフィルターへ少量送ります。ほかのトラックよりLEVELを下げ、左右へPANを振ります。OSC x4のFILTERで全体を柔らかくまとめます。

これらは音作りの出発点です。再生成した音色では元の設定が大きく異なるため、一項目ずつ聴き比べて調整してください。

12 / 困ったとき

症状確認すること
音が出ない電源・PLAY・ブラウザー消音・OSの出力先・トラックMUTE・LEVEL。MODEがPAUSE、HITSが0になっていないか確認。
ATKを上げると音が小さくなるGATEやDIVが短く、立ち上がる前にノートオフになっている可能性があります。鍵盤を保持して比較。
ENVの変化が分かりにくいDLY / REVを下げて原音を確認。長い残響や別トラックの音を分けて聴きます。旧ページは再読み込み。
RELを上げても音が伸びない素材や音源固有の減衰が先に終わる場合があります。持続音を出す音源で比較。
停止しても音が残るENVのREL、ディレイ帰還、リバーブの残響が残っています。すぐ出力を止めたい場合はブラウザーの消音。
音色を変えても発音しない保存済みMODEがPAUSEならFLOWへ変更。プリセット切り替えはMODEを保持します。
保存した状態が見つからないURLのポート・ブラウザーが同じか確認。PROJECTの保存先と、名前画面での確定を確認。
